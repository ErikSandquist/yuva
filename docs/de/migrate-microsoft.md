# Von Outlook.com oder Microsoft 365 umziehen

Beide verbinden sich mit „Sign in with Microsoft“, die Schritte unterscheiden sich aber. Wählen Sie die
Anleitung nach der Adresse des Postfachs:

- Eine Adresse bei `outlook.com`, `hotmail.com` oder `live.com` (ein persönliches Microsoft-Konto): Folgen Sie
  [Von Outlook.com umziehen](migrate-outlook.md).
- Eine Arbeits- oder Schuladresse auf der eigenen Domain Ihrer Organisation: Folgen Sie
  [Von Microsoft 365 umziehen](migrate-microsoft365.md).

Die Übersicht steht unter [Zu Yuva umziehen](migrate.md).
