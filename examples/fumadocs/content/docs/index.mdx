Acme is a small, made-up service that turns text into short summaries. These pages are an example
documentation site: every page ends with "Was this page helpful?", which sends ratings and feedback
to a Yuva inbox, and a discussion area where readers ask and answer in public.

## First request

1. [Install](/docs/install) the client.
2. Create an API key in the Acme dashboard.
3. Call `summarize` from the [API](/docs/api).

```ts
import { Acme } from "acme";

const acme = new Acme({ apiKey: process.env.ACME_API_KEY });
const { summary } = await acme.summarize("A long text…");
```

Something unclear? Start a discussion below; the team and other readers answer on the page.
